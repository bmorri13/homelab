# Log lines that must come out of splunk_out with every generated value removed.
# Templates, not secrets: scripts/cribl-test-mask.py fills each {X:n} with n random
# characters at run time, so no token-shaped string is ever committed.
#   A alnum   L lower alnum   a lower letters   U upper+digits   H hex   N digits
#   B base64 chars   W word chars   Z [A-Z2-7]   E bech32   {uuid}
#   {PRIVATE} is the literal word and {PEMB64} a base64 RSA key header; both are kept
#   out of the file so secret scanners do not flag it.
# A test passes when no filled-in value of 8+ characters is left in the output.
# \n in a template is a newline (multi-line events).
