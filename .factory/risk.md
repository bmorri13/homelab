# Change risk

How risky a change to `bmorri13/homelab` is, and so how much of a person's attention it gets. Written for dependency updates first. A triage agent reads this file; the owner owns it.

## Tiers

| Risk | What it looks like here | Agent does | Person does |
|---|---|---|---|
| Low | Updates whose merge changes nothing that runs, with a long clean record or a check on the branch: Terraform proxmox provider patches and minors (34 merged, none needed a hand; apply is manual), the mcp-for-argocd image (built and smoke-tested on the branch, deployed only when its digest is pinned), and the unifi-network-mcp image while that backend is switched off. | Checks the change against the release notes and this file, and comments a verdict | Merges on the verdict |
| Medium | Anything not matched, and Postgres for Authentik below a major (#332, #456): cribl/cribl digests in the monitoring_stack compose file (#118, #137, #140), the homelab-agents image group (#258, #334, #345), GitHub Actions bumps in workflows (#117, #147, #146, #121), and the Terraform and Packer version pins (#431, #430). | Reads the release notes, checks this repository's settings against the new version, and comments what to watch after the merge | Reviews, then merges |
| High | Anything that deploys on merge through Argo CD and that other things depend on: the ToolHive operator and CRD charts and the gateway's own images (#182, #392, #460), ARC runner scale sets (#153), the OTel collector and Falco charts (#183, #215, #252), Authentik and any Postgres major (#273), plus Vault, External Secrets and cert-manager pins, and host pins such as k3s, Falco and kube-bench. | Writes up what breaks and the steps to roll it out by hand. Never recommends merging unread | Reviews, merges and does the rollout |

## Rules

A change gets the highest tier of every rule that matches it. A change no rule matches is **medium**. The agent may raise a tier when it finds a reason to, never lower one. `Path` is a glob over the files the change touches, `Package` a glob over the package name, `Update` is `*` or a list of `digest`, `patch`, `minor`, `major`.

| Tier | Path | Package | Update | Why |
|---|---|---|---|---|
| high | `infrastructure_tooling/vault/**` | `*` | * | Vault holds the secrets for the whole homelab, so a bad chart bump can seal it or break secret access everywhere. |
| high | `infrastructure_tooling/external_secrets_operator/**,infrastructure_tooling/eso_*/**,infrastructure_tooling/vault_ingress/**` | `*` | * | External Secrets feeds secrets to every component, and a CRD or API version change can stop secret sync cluster-wide. |
| high | `infrastructure_tooling/cert_manager/**` | `*` | * | cert-manager must move one minor at a time, and a jump can break certificate issuance and CRDs. |
| high | `infrastructure_tooling/authentik/**` | `*, !docker.io/library/postgres` | * | Authentik is the login for Splunk and Cribl, and a chart and server image that do not match can lock everyone out. |
| high | `infrastructure_tooling/authentik/**` | `docker.io/library/postgres` | major | A new Postgres major cannot open the old data directory. Move it by hand with a dump and restore. |
| medium | `infrastructure_tooling/authentik/**` | `docker.io/library/postgres` | digest, patch, minor | Restarts the database behind the Splunk and Cribl login for a moment. The data format does not change within a major and a dump is taken nightly, so a revert is clean. |

| low | `infrastructure_tooling/mcp_for_argocd_image/**` | `*` | digest, patch, minor | A merge deploys nothing: the gateway runs this image by a digest pinned in `toolhive_mcp/values.yaml`, which is a separate change. The build and its smoke test run on the branch. |

Once it is on, this is high like the rest of the gateway. |
